# 2026-07-14 工作日志

## 游戏窗口截图脚本
- 创建 `game_screenshot.py`，实现每秒对指定游戏窗口截图，输出 720p (1280x720)
- 依赖：mss (高速截图) + Pillow (缩放) + pywin32 (窗口定位)
- 支持窗口标题模糊匹配、多窗口选择、自动跟踪窗口位置变化
- 按 Ctrl+C 停止，实时显示 FPS 和运行统计

## GUI 启动器 + Bat 文件
- 创建 `screenshot_gui.py`：tkinter 窗口，中央"开始截图"按钮，点击后强制置顶目标窗口并开始截图
- 创建 `启动截图.bat`：双击启动，纯 ASCII 避免 cmd 编码问题，使用 pythonw.exe 无需控制台弹出黑窗

- 智能回退：无匹配时自动扫描所有可见窗口让用户点选目标
- 截图线程独立于 GUI 主线程，避免界面卡死
- 强制置顶技巧：AttachThreadInput + SetForegroundWindow + SetWindowPos 组合
