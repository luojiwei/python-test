## MapleStory 私服游戏角色坐标定位方案咨询

用户在 WingsMS-v0.32 客户端场景下提出"通过截图匹配角色名【罗德候君】来确定坐标"的方案咨询。

**给出的核心建议**（按推荐度）:
1. **内存读取**（pymem + Cheat Engine 找基址）— 首选，1ms 拿到世界坐标
2. **服务器侧主动推送**（用户在搞 OdinMS-based v062 私服，服务端源码可控）— 终极方案，零侵入
3. **纯视觉特征匹配**（匹配角色身体而非文字）— 备选，比文字匹配稳定
4. **截图+文字 OCR/模板匹配** — 不推荐，开销大、装饰文字干扰

**关键反驳点**:
- 截图+匹配 30-100ms 占用，准实时不可能
- 名称带行会标签 `Wing of an Angel` / `Place x繁星` 装饰，需精确截取
- 得到的是像素坐标而非世界坐标，还需转换

**用户偏好记忆**: 喜欢对比表 + 编号列表 + 简洁直接的结论先行风格。

## 角色定位.bat + player_locator_gui.py 创建

基于用户约束（不能内存读取、外观会变、只有角色名"罗德候君"不变），创建了文字模板匹配+追踪窗口的方案。

**文件**:
- `player_locator_gui.py` — tkinter GUI + cv2 模板匹配 + mss 截图 + 线程循环
- `角色定位.bat` — 双击启动器，使用 yolo env（cv2/mss/numpy 已安装）

**功能流程**:
1. 双击 bat → GUI 面板弹出
2. 点击"开始定位" → 自动找 WingsMs 窗口
3. 首次运行：弹出 OpenCV 框选窗口 → 用户拖选"罗德候君"四个字 → 保存为 name_template.png
4. 后续运行：直接用已有模板
5. 后台线程 0.1s 截图一次，模板匹配 → 主线程实时显示红框+坐标
6. 追踪优化：找到后只在 450×280 窗口内搜索，8 帧丢失后全屏重搜

**标记内容**:
- 红色矩形框 = 名字匹配区域
- 红色十字 = 名字中心
- 黄色圆点 = 估计脚底位置（名字底部 + 55px offset）
- 文字标注 = 名字坐标、脚底坐标、置信度

**复用的现有模式**: 窗口 API（enum/find/force_foreground）、mss 截图、tkinter GUI、线程循环、bat 启动器格式，全部对齐现有 rope_marker_gui.py 和 screenshot_gui.py 的代码风格。

### 二、自动打怪脚本（auto_farm.py + 自动打怪.bat）
**三大模块整合**：YOLOv11 怪物检测 + 模板匹配角色定位 + keybd_event 控制

**决策优先级**：
```
同向 + 攻击范围(200×80)有怪 → 脉冲攻击(每0.3s点Ctrl)
反向 + 攻击范围有怪 → 按方向键转身 + 攻击
同平台(±100px)有怪 → 移动靠近最近的
无目标 → 待机
```

**关键迭代修复**：
- 跳跃误判：怪物中心 vs 脚底 → 改用底部 y2 对脚底 cy
- 平台过滤：±30→100px，不同平台怪物跳过
- 攻击键卡死：长按 Ctrl → 脉冲点击(按30ms松)，加 force_release_all 保底
- 方向反转：反方向攻击只改变量没转身 → 真正按方向键转身
- 朝向初始化：启动时 tap 右键 + force_foreground
- 误识别：YOLO_CONF 0.25→0.50，加 debug 帧标注攻击范围+平台范围+置信度
- YOLO 频率：按时间 1.5s 间隔，LOG 也 1.5s 间隔
- 配置：ATTACK_DISTANCE=200, ATTACK_VERTICAL=80, PLATFORM_TOLERANCE=100

**最终配置**：
- TEMPLATE_RECT = (85, 728, 150, 745)
- ATTACK_DISTANCE = 200, ATTACK_VERTICAL = 80
- PLATFORM_TOLERANCE = 100, JUMP_THRESHOLD = -30
- YOLO_CONF = 0.50, YOLO_INTERVAL = 0.5s
- LOG_INTERVAL = 0.5s, INTERVAL = 0.5s
- 攻击：tap('a', 30ms) 脉冲，每 0.3s 一次
- 朝向：启动时 tap('r')，反方向攻击时 tap 方向键转身

**输出**：track_output/debug_XXXXXX.png（标注攻击范围、平台范围、所有怪物框+置信度、TARGET 标记）
