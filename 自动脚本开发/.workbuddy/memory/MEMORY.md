# 项目规则 — 代码生成通用要求

> 以下规则适用于在 `自动脚本开发/` 下创建的所有脚本。
> 每次生成新工具时自动遵循，无需用户重复说明。

---

## 1. 自主执行优先（最高优先级）

- **凡是能自己做的全部自己做，做不到了再找我。**
- 具体范围包括但不限于：
  - 截图、抓帧、图像分析、OCR 识别
  - 运行脚本、调试输出、查看日志
  - 模拟数据、写测试用例、跑测试
  - 各种中间验证、边界情况检查
  - 所有不涉及主体脚本逻辑修改的辅助工作
- **只有当你确实需要我来操作（比如操控游戏窗口、提供只有我知道的信息）时，再来问我。**
- 禁止反复让我"跑一次看看" — 先自己跑通。

## 2. .bat 文件写入规范（PowerShell）

- **必须用 `Default` 编码**（中文 Windows 上 = GBK），不能用 ASCII/UTF-8：
  ```powershell
  [System.IO.File]::WriteAllText($path, $content, [System.Text.Encoding]::Default)
  ```
- 用 ASCII 编码 → 中文字符变 `?` → 路径无效
- 用 UTF-8 无 BOM → cmd 按 GBK 解析 → 乱码

## 3. 编码与路径

- `.bat` 文件：**纯 ASCII 注释**，不使用中文（避免 GBK/UTF-8 乱码）
- `.py` 文件：UTF-8 编码
- 路径含 `(x86)` 等括号且需要在 `if` 块中引用时：用 `setlocal enabledelayedexpansion` + `!VAR!`
- 路径含空格时：始终用双引号包裹
- 避免在 `start` 命令参数中传递含中文的绝对路径，用 `cd /d` + 相对路径代替

## 4. 桌面禁止保存

- **所有输出文件一律保存在工具自身文件夹中**，禁止写入桌面（~/Desktop）
- 包括但不限于：截图、标记图、日志、临时文件
- 例外：崩溃日志（启动失败时用户看不到工具文件夹，桌面是唯一可靠位置）

## 5. 游戏窗口自动恢复/还原

- 截图或检测前：检查游戏窗口是否最小化（`IsIconic`），是则调用 `ShowWindow(hwnd, 9)` 恢复
- 然后用 **Alt 键 + AttachThreadInput 技巧**强制前置窗口（`SetForegroundWindow` 默认会被 Windows 拦截）
- 截完图后将窗口立即调到所有窗口后面，避免遮挡其它窗口

## 6. 测试脚本

- 测试产生脚本和文件在命名上要做区分

## 7. 优先复用现有实现

- 写新脚本/测试脚本前，**先搜索以下两个目录的现有实现**：
  - `D:\Program Files (x86)\Tencent\WorkBuddy\脚本开发工具`
  - `D:\Program Files (x86)\Tencent\WorkBuddy\自动脚本开发`
- 搜索内容：同类功能的 `.py` 脚本、`.bat` 启动器、`config.json` 配置、世界模型等
- 能复用的函数、配置、数据文件就不要重写
- 特别是截图、窗口操作、YOLO 检测、小地图光点查找等通用能力，现有脚本里基本都有

## 8. 遵循用户指定方案

- **如果我指定了实现方式/算法，必须照做，不得擅自替换为其他方案**
- 比如我让你用「模板匹配」找角色、用「YOLO」检测绳梯，你就不能用 HSV 颜色检测或 minimap 推算代替
- 只有在**缺少依赖、环境不支持、逻辑上无法实现**时才反馈给我，由我来决定改方案还是补依赖
