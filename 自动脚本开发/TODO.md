## 职业模板数据文件（🔥 最高优先级）

- **目的**：为每个职业建立独立的数据文件，记录该职业的技能键位、技能动画时长、buff 持续时间、位移距离等静态属性，消除脚本中所有硬编码的职业相关信息
- **方案**：新建 `自动脚本开发/templates/` 目录，每个职业一个 JSON 文件（如 `hero.json`、`archmage.json`），格式：
  ```json
  {
    "class_name": "英雄",
    "skills": {
      "pgup": { "name": "斗气爆发", "animation_ms": 800, "buff_duration": 240, "displacement": 0 },
      "pgdn": { "name": "灵魂突刺", "animation_ms": 450, "buff_duration": 0, "displacement": 50 }
    },
    "attack_key": "a",
    "jump_key": "j",
    "pickup_key": "space",
    "mount_duration": 0.8
  }
  ```
- **改动**：
  - 新建 `templates/` 目录 + 示例模板文件
  - `skill_manager.py` — 从模板读取技能动画时长替代 `0.3`，读取 buff 持续时间
  - `key_actions.py` — 攻击/跳跃/拾取键位从模板读取
  - `config.py` — 删除 `SKILL_KEY_CHOICES`、`SKILL_KEY_LOOKUP` 等硬编码
  - GUI 新增"职业"下拉框，选择后加载对应模板
- **难度**：中（主要是数据整理 + 重构，逻辑改动不大）
- **依赖**：
  - `skills_data.json` 概念（已规划 ✓）— 可并入模板文件

## 技能动画真实时长检测

- **目的**：释放技能后等待真实的施法动画结束再执行下一步操作，替代当前所有技能统一的 0.3s 猜测
- **方案**：新建 `skills_data.json` 静态数据文件，按技能名（键位）记录动画时长等静态属性；`skill_manager.process()` 从文件读取值替代硬编码 `0.3`
- **难度**：低（纯数据 + 一行逻辑改动）
- **依赖**：无

## 巡逻路线热切换

- **目的**：运行时切换固定路线的下拉选项后立即生效，无需停止重启脚本
- **方案**：在 `_loop()` 决策节拍中读取当前下拉框选中的路线名，热更新 `_patrol_waypoints`
- **难度**：中（需处理线程安全问题，路线变更可能打断当前命令）
- **依赖**：无

## 自动识别地图名称

- **目的**：启动脚本时自动识别角色当前所在的地图，无需手动在下拉框选择
- **方案**：截取小地图上方/附近的地图名称文字区域 → OCR 识别 → 与 `discover_maps()` 列表模糊匹配
- **难度**：中（需 OCR 库 + 定义每个地图的名称区域坐标）
- **依赖**：
  - `config.json` 中的 `mm_region`（已有 ✓）— 可作为名称区域推算基准
  - OCR 引擎（未实现 ✗）— 可用 `pytesseract` 或 paddleocr

## Buff 图标 OCR 检测

- **目的**：实时感知角色 buff 状态（技能增伤、无敌等），buff 消失后才补技能
- **方案**：截取游戏 buff 栏固定区域 → OCR / 模板匹配识别每个 buff 图标 → 写入 `GameState.buffs`
- **难度**：高（图标小、数量多、随职业变化）
- **依赖**：
  - 每个地图的 buff 栏屏幕区域定义（未实现 ✗）
  - OCR 引擎或图标模板库（未实现 ✗）
