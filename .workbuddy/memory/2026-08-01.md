  - 启动: `自动标注工具.bat`

- 创建分支 `feature/yolo-gpu-support`，为 YOLO 自动标注工具添加 GPU 支持
  - **GPU 检测**: 机器为 AMD GPU，无 NVIDIA CUDA，无 nvidia-smi
  - **方案**: DirectML (onnxruntime-directml 1.24.4) → 适用于 AMD GPU 的 ONNX GPU 推理
  - **安装**: `pip install onnxruntime-directml` 到 YOLO 环境 (`envs/yolo`)
  - **新建文件**:
    - `gpu_utils.py` — GPU 检测模块 (NVIDIA CUDA / AMD DirectML / CPU)
      - `detect_gpu()`: 检测 GPU 类型/名称/后端
      - `patch_onnx_for_gpu()`: monkey-patch onnxruntime.InferenceSession 注入 DirectML provider
      - `resolve_device()` / `should_use_onnx()`: 设备解析与 ONNX 判断
      - `get_device_list()` / `get_gpu_status_text()`: UI 用
    - `scripts/auto_label.py` — YOLO 自动标注脚本 (subprocess, 支持 GPU+ONNX)
  - **修改文件**:
    - `scripts/train.py`: `--device` 默认 `auto`, 添加 ONNX 自动导出, 训练进度 4 步
    - `scripts/predict.py`: `--device` 默认 `auto`, 添加 GPU 检测
    - `scripts/validate.py`: `--device` 默认 `auto`, 添加 GPU 检测
    - `scripts/yolo_labeler.py`: 添加 `--device` 参数, ONNX+DirectML 自动加载
    - `scripts/gd_label.py`: `--device` 默认 `auto`, 设备自动解析
    - `yolo_tab.py`: 添加设备选择下拉框+GPU状态显示, 标注改为 subprocess, 保存 ONNX 模型
    - `gd_tab.py`: 传递 `--device auto` 到 yolo_labeler
  - **关键设计**:
    - 训练 → PyTorch CPU (DirectML 不支持 Python 3.13 的 torch-directml)
    - 推理 → ONNX Runtime + DirectML GPU 加速 (monkey-patch 自动注入)
    - 用户选 "CPU" → 直接用 .pt 模型, 选 "自动检测" → ONNX+DirectML
    - 训练完成后自动导出 ONNX 模型
    - 通过 `config_cache.json` 持久化设备选择 (key: `yolo_device`)

- **修复脚本启动问题**: Python 3.13.12 (workbuddy 精简版) 无 tkinter 模块
