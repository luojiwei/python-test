## 修复启动报错：找不到 yolo 虚拟环境

用户反馈运行 `自动脚本开发\启动.bat` 和 `脚本开发工具\地图标记工具\地图标记工具.bat` 时弹出 Windows 找不到 `C:\Users\Administrator\.workbuddy\binaries\python\envs\yolo\Scripts\pythonw.exe`。

处理过程：
- 确认 `envs\yolo` 目录不存在，仅存在 `default`。
- 使用 Python 3.13.12 创建 `C:\Users\Administrator\.workbuddy\binaries\python\envs\yolo` 虚拟环境。
- 在 yolo venv 中安装项目所需依赖：`numpy`, `mss`, `opencv-python`, `pillow`, `ultralytics`（含自动拉取的 torch/torchvision 等）。
- 修复 `脚本开发工具\YOLO训练工具\YOLO训练工具.bat`：原脚本写死了 `D:\Program Files (x86)\Tencent\WorkBuddy\...` 路径并指向 `default` 环境，改为 `%~dp0` 相对路径并指向 `yolo` 环境，与其他启动脚本保持一致。
- 导入测试通过：`import numpy, cv2, mss, PIL.Image, ultralytics` 无异常。

注意事项：
- Git Bash 下用 `/c/Users/...` 路径创建 venv 会被翻译到 `F:\c\Users\...`，应使用 PowerShell + Windows 绝对路径。
- 安装 torch（122 MB）耗时较长（约 8 分钟），后续若需重装可考虑使用国内镜像或预下载 whl。
