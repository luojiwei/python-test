# 2026-07-23 关键修改

## 爬梯系统大修
- **ClimbCommand move 阶段**：只按方向键(actions.move)，不加↑/↓，避免走到绳梯前被未标记绳梯吸附
- **mount 阶段**：向上时先按↑+方向 0.1s → 再补跳(保持↑+方向不松) → 上梯后松方向只留↑。向下不需要跳
- **climb_up()**：只按↑（已在绳梯上）
- **is_on_rope 浮点容差**：departure_y + 0.5，避免 py=62.0001 > 62.0 误判为离开绳梯
- **POSITION_THRESHOLD**：2→5，减少到达判定震荡
- **MOUNT_DURATION**：0.8→0.5，减少 mount 过冲
- **move→mount**：去掉 settle 阶段的 release_all()，角色不停下，平滑过渡到 mount
- **锚点到达阈值**：16→12，角色需走到绳梯正下方才触发爬梯

## 僵死检测精确化
- **朝向僵死**：仅攻击命令(TimedAttack/TurnAndAttack)时检测，爬梯/走路不触发
- **绳梯卡住**：x/y 同时 1s 变化 ≤1px + 不在攻击 + 离绳梯 ≤3px 水平 + y 在绳梯范围 ±3，触发后朝 ClimbCommand 原方向爬 0.5s
- transition 完成时加 `actions.release_all()`

## 下跳修复
- JumpDownCommand：持续循环尝试(蹲0.2→↓+跳0.3→间隔)，检测 minimap_y 下降≥3 才算真正下落，超时 3s

## 决策系统改进
- **BFS 寻路**：WorldModel 加 find_shortest_path()，跨平台无直达边时用 BFS 找多跳路径
- **巡逻起始**：首次决策自动定位最近途经点(_current_waypoint_idx=-1)
- **HoldDirCommand**：用 actions.move 替代 move_no_facing，同步朝向
